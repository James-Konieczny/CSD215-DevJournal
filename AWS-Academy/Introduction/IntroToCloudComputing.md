## Cloud Computing

- Cloud computing is the on-demand delivery of compute power, database, storage, applications and other IT resources via the internet with pay-as-you-go pricing
- Hardware is far away somewhere. You use the software, but it's actually infustructure somewhere that someone else is responsible for

- Traditionally, buisnesses had to have their own hardware. This was a lot of work. You need the space, staff, physical security. You need to think about how much space you need. It's a lot to think about and can cost you money if you don't handle it right. That's why offloading it to a third party cloud computing company.

- IaaS (Infrastructure as a service) -> More control over IT resources
- PaaS (platform as a service) -> Middle ground for control over IT resources
- SaaS (software as a service) -> Less control over IT resources

- Cloud Computing is infrastructure (hardware) made as a service
- Sometimes cloud computing is not always cheaper, sometimes (not too often, but not uncommon) private hardware is cheaper
