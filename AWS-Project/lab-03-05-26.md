# AWS Learner Lab Set Up
1. Start Lab. Get your repository up in visual studio code. Open Docker
2. Ensure you're in (.venv), if not, run:  
`source .venv/bin/activate`  
To get out of (.venv), run:  
`deactivate`
3. Ensure dev container is running (check bottom left, should say "Dev Container:") 
4. Go to AWS learners lab, click on "i AWS Details", click "show" next to AWS CLI, copy and paste key into .aws/credentials
5. Run `aws sts get-caller-identity` to check that you're connected to AWS Learners Lab


## Notes
- AWS CLI (command line interface)
    - everything you can do in AWS Console, you can so in AWS CLI
    - AWS CLI commands start with `aws`, then a service like `iam`,`ec2`, or `lambda`, an then the actual command you'd like to run
- in help: j/k to go up and down, q to quit
- the slash button is a search button
- n goes down, N (shift n) goes up
- things inside square[] brackets are options
- things inside angle<>brackets are placeholder
